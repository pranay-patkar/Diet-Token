Token-Diet 2-Stage Compression Architecture

Designed to eliminate LLM prompt bloat while providing mathematical guarantees against silent instruction dropping.

Step 1

Atomic Shielding

Masks code blocks (```...```), markdown tables, lists, YAML structures, and hex codes before sentence splitting.

Step 2

Instruction Detection

Scans for imperative verbs, technical constraints, paths, and field lists, assigning a protected minimum score floor.

Step 3

Hybrid Pre-Filter

Combines BM25 query overlap with character 3-gram fallback to prevent dropping non-exact lexical paraphrases.

Step 4

Semantic MMR & Assembly

Word-level Jaccard + entity-set set difference selects dense non-redundant spans and reassembles in original discourse order.
